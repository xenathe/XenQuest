# XenQuest v0.2.11-beta — Theme Customisation

This update introduces a full in-game theme editor with separate controls for tracker and navigation colours, while preserving the existing questing and navigation features.

## New — Theme Editor

- Added a dedicated **Themes** tab alongside Tracker and Navigation.
- Introduced **Warm Gold**, **Icy Blue**, and **Custom** theme presets with clean two-tone cards.
- Added colour pickers for tracker accent, quest titles, objective text, progress bars, completed quests, and zone headings.
- Added independently customisable navigation title, distance text, and arrow glow colours.
- Added an **Arrow Artwork** option to follow the selected theme or explicitly use the approved Gold/Ice navigation assets.
- Moved the quest-font family selector to Themes; font-size controls remain under Tracker.
- Custom colours are saved with your existing addon settings and update in-game.
- Added a **Reset theme to defaults** control.

## Settings Improvements

- Settings are now organised into clearly labelled sections.
- Widened the settings window, fixed at **580 × 640** across all three tabs.
- Restored minimal, flat Zygor-inspired tabs with a theme-coloured selection underline.
- Kept background opacity exclusively under Tracker settings to avoid duplicate controls.
- Fixed inconsistent edge clipping on all three theme preset cards (Warm Gold, Icy Blue, and Custom).

## Preserved Functionality

- Automatic zone-based quest grouping and manual zone expansion.
- Objective progress bars, completion effects, and quest item shortcuts.
- Smooth 64-frame isometric navigation with the original approved Gold/Ice artwork.
- Discord **Need help?** shortcut and existing saved settings.
- Blizzard's native World Map (no XenQuest World Map overlay).
