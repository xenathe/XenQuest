XenQuest custom font setup

Place your own static TrueType font at:
Interface/AddOns/XenQuest/Media/custom.ttf

Fully restart WoW after installing it. In /xq settings, choose Custom.
The selector now reports Custom (loaded) or Custom (NOT FOUND).
Do not select a variable font if your WoW client does not support it.

This distribution does not include third-party font files.
